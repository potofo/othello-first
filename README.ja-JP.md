# 盤上の八列 リバーシ

[English](README.md) | 日本語

コンピュータと対戦できる、8×8 盤のリバーシ（オセロ形式）ゲームです。
HTML ファイル 1 つで完結しており、ビルドや依存パッケージは不要です。`othello.html` をブラウザで開くだけで遊べます。

## 特徴

- **黒（先手）** / **白（後手）** を選択可能
- 3 段階の強さ
  - **よわい** — ほぼランダム。多く返せる手を少しだけ好みます
  - **ふつう** — 2 手先まで読みます
  - **つよい** — 5 手先まで読み、残り 10 マス以下では最後まで完全に読み切ります
- 打てるマスのヒント表示、直前の手のマーカー、石を置く・返すアニメーション
- 石数のリアルタイム表示と棋譜（`a1`〜`h8` 表記、パスも記録）
- パスと終局の自動判定
- レスポンシブ対応（広い画面ではサイドパネル、スマートフォンでは縦並び）
- OS の設定に合わせたライト / ダークテーマ
- キーボード操作、スクリーンリーダー用ラベル、`prefers-reduced-motion` に対応

## 起動方法

### 方法 1：ファイルを直接開く

`othello.html` をダブルクリックするか、ブラウザ（Chrome / Edge / Firefox / Safari など）にドラッグ＆ドロップしてください。

### 方法 2：ローカルサーバーで配信する

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/othello.html> を開きます。

> フォントは Google Fonts から読み込みます。オフラインでもシステムフォントで動作します。

## 遊び方

1. サイドパネルで自分の石の色と強さを選びます。
2. 小さな点が表示されているマスをクリックして石を置きます。
3. 置いた石と自分の石で挟んだ相手の石がすべて裏返ります。
4. 打てるマスがない場合はパスになります。双方とも打てなくなったら終局で、石の多い方が勝ちです。

「新しく対局する」ボタンでいつでも最初からやり直せます。石の色を変えると新しい対局が始まり、強さの変更は次のコンピュータの手番から反映されます。

## コンピュータの思考

- **評価関数**：マスごとの重み表（角 +100、角の斜め隣 −50 など）と、着手可能数の差（モビリティ）を組み合わせています。角を取った後は、その角に隣接するマスの減点を打ち消します。
- **探索**：αβ 枝刈り付きの negamax 探索。重み表に基づいて手を並べ替え、枝刈りの効率を高めています。
- **終盤**：「つよい」では空きマスが 10 以下になると終局まで読み切り、最終的な石数差が最大になる手を選びます。
